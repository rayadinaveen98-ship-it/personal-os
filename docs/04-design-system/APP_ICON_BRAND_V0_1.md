# Personal OS — App Icon & Brand Mark v0.1

**Status:** Working draft — experience requirements locked, exact artwork not yet chosen

The app icon is the first permanent visual touchpoint of Personal OS. It should immediately feel calm, premium, distinctive and trustworthy.

## 1. Brand intent
The icon should communicate some combination of:
- personal space
- focus
- continuity
- life layers
- reflection
- quiet intelligence

It should not literally try to show every feature.

## 2. Desired qualities
- recognizable at small Android launcher sizes
- simple silhouette
- premium rather than playful-first
- calm rather than high-energy
- distinctive against common productivity icons
- works in light/dark launcher contexts
- compatible with Android adaptive icon requirements

## 3. Avoid
- generic checkmarks
- obvious calendar icon
- generic brain/AI spark symbol
- neon gradients
- complicated miniature dashboards
- text like `Personal OS` inside the icon
- overly detailed mascot artwork that becomes unreadable at launcher size
- using the Tiny Observatory Friend's face as the default launcher icon

## 4. Working concept directions
These are exploration directions, not final choices.

### Direction A — Observatory mark
A minimal framed/orbital shape suggesting a personal world or observatory.

Potential traits:
- soft rounded enclosure
- one inner focal point/orbit
- moss/ivory/dark combinations

### Direction B — Personal portal
A calm rounded doorway/window symbol suggesting entering one's personal space.

### Direction C — Life growth mark
A minimal sprout/leaf form that suggests growth, continuity and a life being cultivated without looking like a wellness-only app.

### Direction D — Life layers
Two or three softly nested forms implying plans, memories and growth coexisting.

### Direction E — Observatory horizon
A minimal horizon/orbit/sun combination that can work as a quiet symbol for present, past and future.

## 5. Adaptive icon
Deliverables must include:
- foreground vector/asset
- background color/layer
- safe-zone testing
- monochrome/themed icon where supported

Critical elements must remain inside Android adaptive-icon safe bounds.

## 6. Splash relationship
The splash mark should use the same core symbol as the launcher icon.
Do not invent a separate unrelated splash identity.

## 7. Wordmark
Where a wordmark is used:
- `Personal OS`
- clean, warm typography
- no futuristic techno font
- restrained spacing

The wordmark may appear on Welcome and selected branding surfaces, but everyday navigation should not constantly repeat it.

## 8. Companion relationship
The approved companion direction is **Tiny Observatory Friend**.

The companion and brand mark must feel like they belong to the same visual world, but they have different jobs:
- **brand mark/icon** = timeless system identity
- **Tiny Observatory Friend** = emotional/living companion layer

The character must not replace the core brand mark. The icon should remain useful even if companion visibility is disabled.

## 9. Color direction
Start from the Warm Personal Observatory palette:
- Warm Ivory `#F5F1E8`
- Moss Sage `#667A61`
- Ink `#252521`
- restrained Gold `#C89B58`

Final icon color should prioritize launcher legibility over forcing every brand color into the mark.

## 10. Final selection process
Before freeze:
1. generate 3–5 clean icon concepts
2. inspect at actual launcher size
3. inspect masked as circle/squircle/rounded square
4. test on light and dark launcher backgrounds
5. choose one direction
6. produce adaptive and monochrome variants

## 11. Acceptance criteria
The final icon must:
- still read clearly at small size
- look intentionally designed, not like a default template
- avoid misleading feature symbolism
- work as the splash mark
- harmonize with the app's calm premium identity
- remain visually distinct from the companion character
