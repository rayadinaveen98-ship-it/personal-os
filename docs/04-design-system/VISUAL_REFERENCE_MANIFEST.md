## Production asset distinction

Frozen **identity/reference** is not the same as final APK asset bytes.

Astra must create/recreate production-ready:
- Minimal Leaf adaptive icon vectors
- Minimal Leaf monochrome/themed icon
- Tiny Observatory Friend runtime state assets/animations

according to the frozen references and `ASSET_LICENSE_MANIFEST_V1.md`.

Do not ship opaque concept boards as full-screen screenshots simply to imitate the look.

## Precedence

If a static Canva reference conflicts with:
1. accessibility/small-screen rules,
2. data truthfulness,
3. actual interactive behavior,
4. frozen semantic design tokens,

then preserve the visual intent while following the written frozen rule.

Astra may not replace the visual identity with a generic Material theme or unrelated mascot/icon set.
